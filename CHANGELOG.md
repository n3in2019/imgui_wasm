## [0.1.0] - 2026-08-13

- Initial imgui-wasm release.
- Native C++ and Python APIs backed by server-side Dear ImGui.
- Browser rendering through draw-data and semantic WASM replay transports.
- Reproducible generated bindings based on pinned `dear_bindings` metadata.
