# Contributing to ImGuiWasm

Thanks for helping improve ImGuiWasm. Bug reports, focused fixes, documentation,
and compatibility improvements are welcome.

## Before you start

- Search existing issues and pull requests before opening a duplicate.
- Use an issue for substantial design changes so the approach can be discussed.
- Keep pull requests focused on one feature or fix.
- Never include build output, downloaded dependencies, virtual environments, or
  local configuration.

## Local setup

Install Rust stable, Git, CMake 3.10+, a C++17 compiler, Emscripten, Node.js,
and Python 3.10+. The installed Python package supports 3.8+, while binding
regeneration uses `dear_bindings` and therefore requires 3.10+.
Then build from the repository root:

```bash
cargo build --workspace
cmake -S imgui-wasm-cpp -B build -DIMGUI_WASM_BUILD_EXAMPLES=ON
cmake --build build
```

The first Rust build fetches the pinned Dear ImGui source into an ignored local
directory. Every Rust build compiles and embeds the browser WASM replay twin.

## Required checks

```bash
cargo test --workspace
cargo build --workspace
cmake -S imgui-wasm-cpp -B build -DIMGUI_WASM_BUILD_EXAMPLES=ON
cmake --build build
node --check imgui-wasm-core/frontend/imgui_wasm.js
node --check imgui-wasm-core/frontend/imgui_wasm_callstream.js
python3 -m py_compile imgui-wasm-python/tools/generate_bindings.py
git diff --check
```

Use clear commit messages and explain user-visible behavior, testing, and any
compatibility impact in the pull request.

## Generated bindings

The C API and metadata are generated by `dear_bindings`; the Python API, Rust
export layer, and call-stream artifacts are generated from that metadata:

- `imgui-wasm-python/imgui_wasm/imgui.py`
- `imgui-wasm-core/src/generated_imgui_api.rs`

Regenerate both together with:

```bash
python3 imgui-wasm-core/tools/dear_bindings/generate.py
```

This command fetches the pinned Dear ImGui and `dear_bindings` revisions into a
temporary directory. Include metadata and all generated output in the same
change so reviewers can reproduce it.

## Reporting security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md)
instead.
